# تطبيق مطبخ لانا (أندرويد + طباعة بلوتوث)

يفتح شاشة المطبخ من الموقع، ويطبع الطلبات مباشرة على طابعة البلوتوث بالعربي بمقاس 80mm — بدون كمبيوتر.

## بناء ملف APK (مرة واحدة)
1. نزّل وثبّت Android Studio على أي كمبيوتر.
2. افتح المجلد `android-print-app` من Android Studio (Open).
3. انتظر حتى ينتهي التحميل، ثم من القائمة: Build → Build APK(s).
4. الملف يظهر في `app/build/outputs/apk/debug/app-debug.apk` — انقله للتابلت وثبّته.

## التشغيل على التابلت
1. من إعدادات البلوتوث في التابلت: اقترن بالطابعة (الرمز غالباً 0000 أو 1234).
2. افتح تطبيق «مطبخ لانا» واسمح بإذن البلوتوث.
3. من لوحة الإدارة ← الطابعات: ولّد رمزاً جديداً للطابعة وانسخه.
4. في التطبيق اضغط زر «⚙ الطابعة» أسفل الشاشة، الصق الرمز، اختر الطابعة، واحفظ.
5. من لوحة الإدارة اضغط «طباعة تجريبية» للتأكد.

ملاحظة: التطبيق يجب أن يبقى مفتوحاً (الشاشة تبقى مضاءة تلقائياً). وإذا كان برنامج الطباعة على الكمبيوتر ما زال يعمل بنفس الرمز فأطفئه، حتى لا يأخذ الطلبات قبل التابلت.
